### 🙋 Sobre mim

Full Stack Developer baseado em Marília, SP. Construo produtos do zero ao deploy — da modelagem de dados à interface final. Na **Movingpay**, liderei o desenvolvimento de uma plataforma de link de pagamento, atuando em arquitetura, back-end e front-end. Hoje, na **SolverSys**, desenvolvo interfaces e integrações para clientes corporativos, participando da camada de dados até a entrega final.

Stack principal: React.js, Next.js, Node.js, TypeScript e Flutter, com MySQL, Firebase e SQL Server. Versionamento com Git/GitHub como padrão, código pensado para manutenção — legibilidade e reuso antes de esperteza.

Fora do trabalho, mantenho projetos próprios: apps em Flutter, o PairMoney e automações que resolvem problemas reais de processo.

MBA em Engenharia de Software pela FIAP • Inglês intermediário, em evolução constante.
